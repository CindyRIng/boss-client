# boss-client 部署与使用

> 目标：在一台 Linux 机器上常驻 `boss-client`，通过 CLI / REST / MCP 给 Agent 与业务系统提供 BOSS直聘只读查询。
> 环境配套见 [04-环境配套.md](./04-环境配套.md)。

---

## 1. 运行要求

| 项 | 要求 |
| --- | --- |
| OS | Linux（已在 NixOS 26.11 验证） |
| Node.js | ≥ 22.5（通过 `~/cloak-env` 的 FHS 内 Node 22.23.2 运行） |
| 浏览器 | `~/cloak-env` 提供 cloakbrowser 0.6.5 + Chromium 146 |
| 显示 | 登录/验证码需要 **headful**（Wayland/X11 或 Xvfb） |
| 网络 | 能访问 `www.zhipin.com`、`static.geetest.com`、`img.bosszhipin.com` |
| 账号 | 本人/授权 BOSS直聘求职者账号（只读） |

> 没有 `~/cloak-env` 时，`health`/`docs` 等不需要浏览器的命令仍可直接 `node dist/main.js`，但查询/LBS 登录会失败。

---

## 2. 安装

```bash
git clone git@github.com:CindyRIng/boss-client.git
cd boss-client

npm install
cp .env.example .env
# 编辑 .env：BOSS_API_TOKEN 必须改；短信登录再填 BOSS_PHONE
npm run build
npm test
npm run gen

# 安装全局 boss 命令（项目移动后需重建软链）
ln -sf "$PWD/bin/boss-run" ~/.local/bin/boss
boss health
```

> `npm install` 可能提示 `node:sqlite` 是实验特性；这是 Node 22 的正常 warning，不影响使用。

## 3. 配置

配置优先级：**CLI 参数 > 环境变量 > 默认值**。`boss` 启动时自动加载项目根目录 `.env`（可用 `BOSS_ENV_FILE` 指定其他路径）。

### 3.1 必改

```dotenv
BOSS_API_TOKEN=一个足够长的随机字符串
BOSS_PHONE=你的手机号          # 仅短信登录需要
```

### 3.2 常用项

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `BOSS_BASE_URL` | `https://www.zhipin.com` | 站点 |
| `BOSS_PROFILE_DIR` | `~/.boss-client/profile` | 独立浏览器 profile |
| `BOSS_HEADLESS` | `false` | 登录/验证码必须 false；已有登录态可设 true |
| `BOSS_CACHE_DB` | `~/.boss-client/cache.db` | SQLite 缓存 |
| `BOSS_HOST` | `127.0.0.1` | 只允许本机 |
| `BOSS_PORT` | `8788` | REST 端口 |
| `BOSS_CITIES` | `101090100` | 默认城市码（逗号分隔多城市） |
| `BOSS_RATE_PER_MIN` | `12` | 上游请求/分钟 |
| `BOSS_MAX_PAGES` | `5` | 单任务最多页数 |
| `BOSS_PAGE_DELAY_MS` | `2500` | 页间基础延迟 |
| `BOSS_CODE37_COOLDOWN_SEC` | `60` | code37 冷却 |
| `BOSS_HEARTBEAT_SEC` | `300` | 登录态心跳 |
| `BOSS_LOG_FILE` | `~/.boss-client/logs/boss.log` | JSONL 日志 |
| `BOSS_LOG_LEVEL` | `info` | debug/info/warn/error |

完整列表见 `.env.example`。

### 3.3 多城市

`BOSS_CITIES` 支持逗号分隔；单次请求可用 `--city` / `cityCode` 覆盖。城市码可用 `boss cities list` 查看，`--refresh` 从 BOSS 城市接口刷新。

## 4. 登录

### 4.1 桌面/带显示机器（推荐）

```bash
boss login            # 默认短信
boss login --qr       # 二维码
```

- 短信：打开 headful 浏览器 → 自动填手机号/点发送 → 浏览器中完成极验 → 终端输入短信验证码。
- 二维码：打开 headful 浏览器 → 终端直接渲染二维码（ANSI 半块字符）→ 用 BOSS App 扫码。
- 成功后 profile 持久化；杀掉进程/重启后 `boss status` 应直接 `loggedIn=true`。

### 4.2 无桌面服务器（Xvfb）

登录/验证码需要 DOM/可视浏览器；在 systemd 服务中增加：

```ini
Environment=DISPLAY=:99
ExecStartPre=/usr/bin/Xvfb :99 -screen 0 1440x900x24
```

然后用 REST 中继把二维码/验证码交给远程的人或 agent（见 4.3）。

### 4.3 REST 中继（远程/Agent）

```bash
# 1) 开始短信登录
curl -X POST http://127.0.0.1:8788/v1/session/login \
  -H "Authorization: Bearer $BOSS_API_TOKEN" -H "content-type: application/json" \
  -d '{"mode":"sms"}'
# -> { data: { loginId, state:"awaiting_captcha", captcha:{ mainBase64, tipBase64, ... } } }

# 2) 把 captcha 图片展示给人/agent；提交点击坐标（0-1 归一化，按提示顺序）
curl -X POST http://127.0.0.1:8788/v1/session/login/<loginId>/captcha \
  -H "Authorization: Bearer $BOSS_API_TOKEN" -H "content-type: application/json" \
  -d '{"kind":"click","points":[{"x":0.68,"y":0.62},{"x":0.17,"y":0.54}]}'

# 3) 提交短信码
curl -X POST http://127.0.0.1:8788/v1/session/login/<loginId>/sms \
  -H "Authorization: Bearer $BOSS_API_TOKEN" -H "content-type: application/json" \
  -d '{"code":"123456"}'
```

二维码模式：

```bash
curl -X POST http://127.0.0.1:8788/v1/session/login \
  -H "Authorization: Bearer $BOSS_API_TOKEN" -H "content-type: application/json" \
  -d '{"mode":"qr"}'
# data.qr.pngBase64 交给任意前端展示；轮询 GET /v1/session/login/<loginId>
```

> 首次/掉线必须人工一次；客户端不自动破解极验。会话实测约 10 天，`status.session.remainingSec` 可看剩余时间。

## 5. 使用

### 5.1 CLI

```bash
boss health
boss status

# 搜索 + 翻页
boss search jobs --keyword 外贸 --city 101090100 --page-size 15 --pages 1
boss jobs list --query-id q_20261111_ab12cd --page 2

# 岗位详情
boss jobs detail --job-id 9b480e5d72caccd303Zz3du6FFFS
# 也可直接给 securityId（省一次页面解析）
boss jobs detail --job-id 9b480e5d72caccd303Zz3du6FFFS --security-id <securityId>

# 公司
boss companies list --query-id q_20261111_ab12cd --fetch-pages 1
boss companies detail --id 'd6c15290231e61e21Hd70965EFY~'
boss companies jobs --id 'd6c15290231e61e21Hd70965EFY~'

# 城市 / 缓存
boss cities list --refresh
boss cache stats
boss cache clear --expired
```

- 输出默认统一 envelope JSON；`--format table` 为简表。
- 同一查询条件 2h 内会命中 SQLite 缓存；`--refresh` 可绕过（REST 用 `refresh=true`）。

### 5.2 REST

```bash
boss serve --port 8788
curl http://127.0.0.1:8788/docs
curl http://127.0.0.1:8788/openapi.json
curl -H "Authorization: Bearer $BOSS_API_TOKEN" http://127.0.0.1:8788/v1/status
curl -X POST http://127.0.0.1:8788/v1/search/jobs \
  -H "Authorization: Bearer $BOSS_API_TOKEN" -H "content-type: application/json" \
  -d '{"keyword":"外贸","cityCode":"101090100","page":1,"pageSize":15,"pages":1}'
```

### 5.3 MCP

```json
{
  "mcpServers": {
    "boss-client": {
      "command": "/home/you/boss-client/bin/boss-run",
      "args": ["mcp"],
      "env": { "BOSS_API_TOKEN": "change-me" }
    }
  }
}
```

工具清单：`spec/mcp-tools.json`。SKILL 见 `skills/boss/SKILL.md`。

## 6. systemd 常驻

```bash
mkdir -p ~/.config/systemd/user
cp systemd/boss-client.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now boss-client
systemctl --user status boss-client
journalctl --user -u boss-client -f
```

默认 unit 以 `%h/boss-client` 为工作目录、读取 `%h/boss-client/.env`、执行 `bin/boss-run serve`。项目不在 home 下时修改 `WorkingDirectory`/`EnvironmentFile`/`ExecStart`。

## 7. 观测与排障

| 现象 | 处理 |
| --- | --- |
| `HEADFUL_REQUIRED` | 登录/验证码需要 DISPLAY；桌面登录或 Xvfb，或改 `BOSS_HEADLESS=false` |
| `ALREADY_RUNNING` | 同 profile 已有进程；`pgrep -af boss` 查，必要时删 `~/.boss-client/run/boss.lock` |
| `AUTH_REQUIRED` / `SESSION_EXPIRED` | 会话失效；`boss login` 重新登录 |
| `UPSTREAM_BLOCKED` | code37 风控；等待 `status.risk.cooldownUntil` 后重试，降低频率 |
| `RATE_LIMITED` | 按 `retryAfterMs` 退避；降低 `BOSS_RATE_PER_MIN` |
| `SMS_RATE_LIMITED` | 短信频控；等几分钟再 `boss login` |
| `captcha 不出现/找不到二维码` | 登录页可能改版；看 `logs/boss.log`，必要时更新 adapters |
| SQLite warning | Node 22 实验特性；可用 `BOSS_CACHE_DRIVER=memory` 临时禁用 SQLite |
| 浏览器启动失败 | 检查 `~/cloak-env/bin/cloak-env-info`、DISPLAY、profile 是否被占用 |

日志默认 `~/.boss-client/logs/boss.log`（JSONL，按大小轮转），不记录手机号/验证码/cookie/token。

## 8. 升级/维护

```bash
cd boss-client
git pull
npm install
npm run build
npm test
npm run gen
systemctl --user restart boss-client
```

- 升级 cloakbrowser 需同步 `package.json` 精确版本；0.7.x 起需要 license key，本项目锁定 0.6.5。
- 修改接口/领域模型后：`npm run gen` 更新 `spec/`，`npm run gen:check` 做 CI 漂移检查。

## 9. 安全与数据

- REST 仅 `127.0.0.1` + Bearer；不要把端口暴露到公网。
- `~/.boss-client/profile`、`session.json`、`cache.db`、日志均为 600/700 权限，含登录态，注意备份/清理。
- 缓存只存结构化字段（岗位/公司/详情），不存 raw 响应/HTML、cookie、验证码。
- 默认 TTL：岗位列表 2h、岗位详情 12h、公司详情 7d、公司全部职位 2h、queryId 24h。
- 只读；不沟通、不投递、不改简历；请遵守 BOSS直聘服务条款。
